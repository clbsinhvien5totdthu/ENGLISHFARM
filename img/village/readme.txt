==================================================
ABOUT
==================================================

Thank you for downloading the Tiny Top-Down Village Pack!

This pack contains 58 unique top-down pixel-art buildings,
designed for RPGs, cozy games, farming games, life sims,
adventure games, fantasy towns and other indie projects.

Each building is created on an 80x80 pixel canvas and
included as an individual PNG file with a transparent
background.

The collection includes homes, shops, workshops,
public buildings, profession-themed houses and special
fantasy structures, making it easy to build a lively
little village or town.
